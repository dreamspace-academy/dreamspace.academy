Brand colours

Both come from the logo itself. Purple is the brand and carries structure; orange is the single accent, one thing per view.

DREAMSPACE is set in the brand purple, ACADEMY and its two rules in the brand orange.

Brand purple #690aad RGB 105, 10, 173 The brand: primary buttons, links, the brand itself. White text on it 9.3:1.
Brand orange #ff6c00 RGB 255, 108, 0 The accent: fills, large numerals, the hero button. Dark text on it 6.3:1; never small text on a light ground.

Typography

Two families, and no third: Poppins sets anything structural, Inter anything read at length.

Aa Poppins

Headlines, eyebrows, numerals, buttons, table headers. Geometric, which echoes the hexagon.

Brand weights 600, 700, 800; the site ships 700. SIL Open Font License.
Aa Inter

Body copy, captions, tables and the interface. A large x-height that holds up at small sizes.

Brand weights 400, 500, 600; the site ships 400 and 600. SIL Open Font License.
The logo has its own faces

DREAMSPACE is set in Squada One and ACADEMY in Teko. They belong to the lock-up and nowhere else: never set a heading in them to match the logo.

Rules

  • Headlines set tight: letter-spacing about -0.02em, line height about 1.05.
  • Body text sets at 1.55 line height, about 72 characters to a line.
  • Never set body copy in Poppins, at any size.
  • Eyebrows and small orange labels use orange 700, never the brand orange.
